# ハンドマウス操作ガイド

Webカメラに写した手の形と位置で、Windowsのマウスを操作するツールの使い方。カメラ映像は表示されず、デスクトップ上に手の骨格だけが透過表示される。既定は**右手のみ**、カーソルの基準点は**手のひら中心**。

閲覧用のWeb版（同じ内容、ジェスチャーの図つき）: https://claude.ai/artifact/SsxowPdzi2hpQxHUSFJXqA 。詳細な設定項目は [README.md](../README.md) を参照。

## 起動と停止

1. 起動する — `python scripts/hand_mouse.py`（または `run_hand_mouse.bat`）。画面上部中央に「○ 操作: 無効」が出れば起動している。
2. 右手を**開いて**カメラの前に出す — カメラ中央あたりに。デスクトップ上に灰色の骨格が浮けば認識されている（「手を開いてカメラに見せてください」の表示が消える）。いきなりグーを出すと検出されないことがある。左手は無視される（「右手だけを使います」と表示）。
3. 操作を有効にする — 骨格が出た状態で**グー（4本指を握り込む）を2秒保持**（画面に「グー保持中 x.x / 2.0 秒」と出る）、または `Ctrl+Alt+H`。表示が「● 操作: 有効」（緑）になり、骨格が水色に変わる。
4. 終了する — `Ctrl+Alt+Q`。どのウィンドウにフォーカスがあっても効く。

安全のため起動直後はマウス操作が無効。骨格が手に追従することを確かめてから有効にする。

## 画面の見方

| 表示 | 意味 |
|---|---|
| 状態表示（上部中央） | 有効／無効、現在のモード、案内（「手がカメラの端に近いです」など） |
| 手の骨格 | 距離に関係なく一定サイズ（手のひら長70px）。手首の下にモード名 |
| リング | カーソル基準点（手のひら中心）に重なる輪。**リングの位置＝クリック位置** |

リングの色: 水色＝移動中／黄色（太い）＝クリック準備でカーソル固定中／緑（塗り）＝左クリック・ドラッグ中／赤（塗り）＝右クリック／灰色＝操作無効。親指が近づくほどリングは縮む。

## ジェスチャー

| ジェスチャー | 動作 |
|---|---|
| 手を開く（グー以外の形） | カーソル移動。人差し指を立てる必要はない |
| 親指＋人差し指をくっつける | 左クリック。つまんだまま動かすとドラッグ＆ドロップ |
| 親指＋薬指をくっつける | 右クリック。人差し指は伸ばしたまま。薬指を握り込んだ状態では反応しない |
| チョキ（人差し指＋中指）を上下 | スクロール（上に動かすと上へ） |
| グーを2秒保持 | 有効／無効の切り替え。半開きやつまんだ形はグーとみなされない |
| 両手ピンチの間隔 | ズーム（Ctrl＋ホイール）。`use_hand` を `both` にしたときのみ |

カメラ画像は鏡像扱いなので、手を右に動かすとカーソルも右に動く。

## 上手に使うコツ

- **クリックは黄色いリングが出てから**: 親指が近づき始めるとカーソルが固定される。そのまま閉じれば固定位置でクリックできる。固定は手が30px以上動くか1秒で自動解除。左クリックは「親指を一度離してから近づけた」ときだけ成立するので、指を寄せたままの姿勢では誤クリックしない。連続でクリックするときは間に親指を離す。
- **細かい震えは気にしない**: カーソル周囲12px以内の揺れは無視される。
- **手はカメラの中央寄りで**: 端に寄ると「手がカメラの端に近いです」が出て関節推定が荒れる。画面下端（タスクバー）を狙うときは特に注意。カメラを下向きにする・椅子を下げるのが効く。
- **疲れたら手を下ろす**: カメラ外に出せばカーソルはその場に止まり、戻すと直前の位置から滑らかにつながる。

## ホットキーと安全装置

| キー | 動作 |
|---|---|
| `Ctrl+Alt+H` | 有効／無効の切り替え |
| `Ctrl+Alt+R` | トラッキング状態をリセット（押しっぱなしのボタンも離す） |
| `Ctrl+Alt+S` | 左右判定を入れ替える（右手が灰色で「左手と判定 → 無視中」になるとき。設定に保存） |
| `Ctrl+Alt+Q` | 終了 |

いずれもグローバルホットキー。暴走したら `Ctrl+Alt+Q`。そのほか: 起動直後は無効／無効化・終了時にボタンを必ず離す／カーソルは画面端に張り付かない。

感度調整やカメラの映り方の確認は `python scripts/hand_mouse.py --display preview`（この画面では `Space`／`R`／`Esc` も使える）。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 骨格が出ない | グーを出していないか（閉じた手は検出されにくい。まず開いた手を見せる）。`--display preview` で映像を確認。「カメラOFF」の絵なら物理シャッター・カメラOFFキー・プライバシー設定。手が灰色で描かれ「左手と判定 → 無視中」と出ているなら左右判定が逆。`Ctrl+Alt+S` で入れ替える |
| 急に反応しない | 「○ 操作: 無効」になっていないか。グー2秒で無効化される。`Ctrl+Alt+H` かグーで戻す |
| クリック位置がずれる | 黄色いリングが出てから閉じる。リングの位置がクリック位置（指先ではない） |
| 右のつもりが左クリック | 薬指をつまむとき人差し指を伸ばして親指から離す |
| カーソルが震える | `stabilizer_radius` を 18 に。手の絵だけ震えるなら `skeleton_smoothing` を 0.2 に。手元を明るくする |
| 画面下端だけ不安定 | 手が映像の下端に寄っている。カメラを下向きに／椅子を下げる。設定なら `active_margin_bottom` を 0.40 |
| 動かしている途中で固定される | `pinch_arm` を 0.55 に下げるか 0 で固定機能を無効化 |
| オーバーレイが隠れる | 全画面アプリの上には出ないことがある。`--display preview` を使う |

## 設定の早見表

`scripts/hand_mouse_config.json`（初回起動時に自動生成。変更後は再起動）。

| 項目 | 既定値 | 説明 |
|---|---|---|
| `use_hand` | `right` | 操作に使う手。`left` / `both` |
| `right_click_finger` | `ring` | 右クリックの指。`middle` / `pinky` |
| `cursor_landmark` | `palm` | 基準点。`index_mcp` / `index_tip` |
| `stabilizer_radius` | 12.0 | 不感帯の半径[px] |
| `pinch_arm` | 0.7 | クリック準備でカーソル固定する距離。0で無効 |
| `pinch_on` / `pinch_off` | 0.40 / 0.62 | クリック判定の距離 |
| `pinch_confirm_frames` | 2 | 連続フレーム数だけ閉じていたらクリック確定 |
| `pinch_require_approach` | true | 親指が一度離れてから近づいたときだけ左クリック |
| `active_margin_x` | 0.18 | 操作エリアの左右余白 |
| `active_margin_top` / `active_margin_bottom` | 0.10 / 0.32 | 操作エリアの上下余白 |
| `overlay_hand_size` | 70 | 描画する手の大きさ[px] |
| `overlay_alpha` | 0.85 | オーバーレイの不透明度 |
| `fist_toggle_sec` | 2.0 | グーの保持時間[秒] |
| `enable_on_start` | false | 起動直後から有効にする |
| `display_mode` | `overlay` | `preview` / `none` |

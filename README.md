# vr-ui — Webカメラのハンドトラッキングでマウスを操作する

Webカメラに写した手の形と位置をMediaPipeで解析し、VRのハンドトラッキングのような
感覚でWindowsのマウスカーソルを操作するツールです。カメラ内の「操作エリア」が
画面全体に対応する**絶対座標マッピング**方式で、手を上げた位置にカーソルが飛びます。

デスクトップ上には**手の骨格だけが透過表示**され（カメラ映像は出ません）、
クリックは下のウィンドウへ素通しするので、作業画面を隠しません。

## 必要環境

- Windows 10 / 11
- Python 3.8以上（動作確認: 3.12.7）
- Webカメラ（640x480 / 30fps程度で十分）

## セットアップ

```bash
pip install -r requirements.txt
```

```bash
python scripts/download_model.py
```

手のランドマーク検出モデル（約7.8MB）を `models/hand_landmarker.task` に保存します。
社内プロキシ等でダウンロードできない場合は、スクリプト内のURLをブラウザで開いて
同じ場所に手動で保存してください。

## 起動

```bash
python scripts/hand_mouse.py
```

`run_hand_mouse.bat` をダブルクリックしても起動できます。

**安全のため、起動直後はマウス操作が無効**になっています。まず**手を開いてカメラに見せ**、
灰色の骨格が出たら**グーを2秒保持**（または `Ctrl+Alt+H`）で有効化してください。
いきなりグーを出すと検出されないことがあります（手のひら検出は開いた手が前提のため）。

| 起動オプション | 内容 |
|---|---|
| `--display overlay` | 手の骨格だけを透過表示（既定） |
| `--display preview` | カメラ映像のウィンドウを表示（感度調整・デバッグ用） |
| `--display none` | 何も表示しない（ホットキーのみで操作） |
| `--camera 1` | 使用するカメラ番号を指定 |
| `--hand both` | 操作に使う手（`right` / `left` / `both`）。設定ファイルより優先 |
| `--swap-hands` | 左右の判定が逆になる環境で判定を入れ替える |
| `--enable` | 起動直後からマウス操作を有効にする |
| `--config <path>` | 設定JSONのパスを指定 |

## 画面表示（オーバーレイ）

- 手の骨格は**カメラとの距離に関係なく一定サイズ**で描かれ、カーソルの基準点（既定は手のひら中心）が
  実際のカーソル位置に重なります。リングの位置がそのままクリック位置です
- リングはピンチが閉じるほど縮み、クリック中は塗りつぶされます
- 親指が近づき始めるとリングが**黄色**になり、その間カーソルは固定されます
  （ピンチ動作で指先が動いてもクリック位置がずれないようにするため）
- 手元に現在のモード名（カーソル移動／左クリック など）が付いて回ります
- 画面上部中央に「操作: 有効／無効」と現在のモードを表示します
- 操作が無効のときは骨格が灰色になります

オーバーレイはクリックを素通しし、フォーカスも奪いません。
初めて使うときは `--display preview` でカメラ映像と操作エリア（水色の枠）を確認しておくと、
手をどこに出せばよいか掴みやすくなります。

## ジェスチャー

| ジェスチャー | 動作 |
|---|---|
| 手を開く（グー以外の形） | カーソル移動（基準点は手のひら中心） |
| 親指＋人差し指をくっつける | 左クリック |
| 親指＋人差し指をくっつけたまま動かす | ドラッグ＆ドロップ |
| 親指＋薬指をくっつける | 右クリック（指は `right_click_finger` で変更可） |
| チョキ（人差し指＋中指）を上下に動かす | スクロール |
| 両手でピンチし、手の間隔を広げる／狭める | ズーム（Ctrl＋ホイール）※ `use_hand` が `both` のときのみ |
| グー（4本指を握り込む）を2秒保持 | マウス操作の有効／無効を切り替え |

カメラ画像は鏡像として扱うので、手を右に動かすとカーソルも右に動きます。
既定では**右手だけ**を使い、左手が映っても無視します（`use_hand` で変更可）。
無視している手は灰色の骨格で描かれます。右手を出しているのに灰色で
「右手だけを使います（左手と判定 … → 無視中）」と表示される場合は、左右判定が逆になっています。
**`Ctrl+Alt+S`** で判定を入れ替えてください（設定に保存されるので次回以降も有効）。
判定がどうしても安定しない環境では `--hand both` で両手を使う設定にできます。

## 安全装置

| 操作 | 内容 |
|---|---|
| **`Ctrl+Alt+H`** | マウス操作の有効／無効を切り替え |
| **`Ctrl+Alt+R`** | トラッキング状態をリセット |
| **`Ctrl+Alt+S`** | 左右判定を入れ替える（設定に保存。右手が「左手」と判定されるときに） |
| **`Ctrl+Alt+Q`** | 終了 |

いずれも**どのウィンドウにフォーカスがあっても効く**グローバルホットキーです。
暴走したと感じたら `Ctrl+Alt+Q` です。`--display preview` のときは、プレビューウィンドウ上で
`Space`（有効切替）/ `R`（リセット）/ `Esc`（終了）も使えます。
終了時・無効化時には押しっぱなしのマウスボタンを必ず離します。

## 設定の調整

初回起動時に `scripts/hand_mouse_config.json` が生成されます。主な項目:

| 項目 | 既定値 | 説明 |
|---|---|---|
| `display_mode` | `overlay` | `overlay` / `preview` / `none` |
| `overlay_alpha` | 0.85 | オーバーレイの不透明度（0.0〜1.0） |
| `overlay_hand_size` | 70 | 描画する手の大きさ（手のひらの長さ[px]）。0で生の写像サイズ |
| `pinch_arm` | 0.7 | 親指が人差し指へこの距離まで近づいてきたらカーソルを固定（クリック準備）。0で無効 |
| `arm_cancel_px` / `arm_timeout_sec` | 30 / 1.0 | 固定中に手がこれ以上動く、またはこの秒数ピンチしなければ固定を自動解除 |
| `cursor_landmark` | `palm` | カーソルの基準点。`palm`（手のひら中心、最も安定）/ `index_mcp`（人差し指の付け根）/ `index_tip`（指先。狙いやすいがブレる） |
| `active_margin_x` | 0.18 | 操作エリアの左右の余白。小さくすると手の移動量が減るが、端が使いにくくなる |
| `active_margin_top` / `active_margin_bottom` | 0.10 / 0.32 | 操作エリアの上下の余白。下を大きく取ると、手がフレームから切れる前に画面の一番下へ届く |
| `edge_zone` / `edge_stabilizer_boost` | 0.15 / 1.5 | フレーム端からこの範囲では、近いほど不感帯を最大（1+1.5）倍に広げ平滑化を強める |
| `reference_palm_size` | 0.15 | 手のひら長の基準。これより大きく映るほど不感帯を広げる（最大2倍） |
| `filter_min_cutoff` | 0.35 | 小さくするほど滑らか（ただし遅延が増える） |
| `filter_beta` | 0.0015 | 大きくするほど速い動きへの追従を優先する |
| `stabilizer_radius` | 12.0 | この半径[px]以内の揺れを無視する不感帯。震えが残るなら18前後に、反応が鈍いなら6前後に |
| `skeleton_smoothing` | 0.25 | 表示する骨格の平滑化（0〜1、小さいほど滑らか）。操作には影響しない |
| `pinch_on` / `pinch_off` | 0.40 / 0.62 | クリック判定の距離（手の大きさで正規化）。誤クリックが多ければ `pinch_on` を下げる |
| `pinch_confirm_frames` | 2 | この連続フレーム数だけ閉じていたらクリック確定（1フレームのノイズを捨てる） |
| `pinch_require_approach` | true | 親指が一度離れてから近づいたときだけ左クリック。最初から指が近い姿勢では発火しない |
| `right_click_finger` | `ring` | 右クリックで親指とつまむ指。`ring`（薬指）/ `middle`（中指）/ `pinky`（小指） |
| `use_hand` | `right` | 操作に使う手。`right` / `left` / `both`。`both` 以外では両手ズームは使えない |
| `swap_handedness` | false | 左右の判定が逆になる場合に true |
| `handedness_min_score` | 0.8 | 左右判定の信頼度がこれ未満の手は無視しない（グーは判定が不安定なため） |
| `handedness_switch_frames` | 6 | 手が1つのとき、採用／無視を切り替えるまでの連続フレーム数 |
| `scroll_gain` | 14.0 | スクロール量の倍率 |
| `zoom_gain` | 22.0 | ズーム量の倍率 |
| `fist_toggle_sec` | 2.0 | グーで有効／無効を切り替えるまでの保持時間 |
| `num_hands` | 2 | 1にすると少し軽くなる（ズームは使えなくなる） |
| `enable_on_start` | false | trueにすると起動直後から操作が有効になる |

## トラブルシューティング

**手を出しても何も表示されない**
グーを出していませんか？ 閉じた手は新規に検出されにくいので、まず開いた手を見せてください。
それでも出ない場合はカメラが手を検出できていません。`--display preview` でカメラ映像を確認してください。
映像が「カメラOFF」の絵になっている場合は、ノートPCの物理シャッター（レンズ横のスライド）や
F8等のカメラOFFキー、メーカー製ユーティリティのプライバシー設定でカメラが塞がれています。

**オーバーレイが他のウィンドウに隠れる**
全画面アプリや一部の最前面ウィンドウの上には出ないことがあります。
オーバーレイは定期的に最前面へ戻しますが、隠れたままなら `--display preview` を使ってください。

**動きがカクつく / 反応が遅い**
暗い場所ではカメラが自動で露光時間を伸ばし、フレームレートが半減します。
手元を明るくするのが最も効果的です。`num_hands` を1にするのも有効です。

**カーソルが細かく震える / 位置が定まらない**
`stabilizer_radius` を 15 程度に上げると静止時の揺れが消えます。まだ揺れるなら
`filter_min_cutoff` を 0.25 程度まで下げてください（遅延は増えます）。逆にキビキビ動かしたいなら 0.6〜1.0 に上げます。
カーソルは止まっているのに手の絵が震える場合は `skeleton_smoothing` を 0.2 程度に下げてください。
`active_margin_x` / `active_margin_top` を小さくすると手の動きに対するカーソルの倍率が下がり、
震えの影響も小さくなります（そのぶん腕を大きく動かす必要があります）。

**画面の端（特に下のタスクバー）を狙うときだけ不安定になる**
手がカメラ映像の端に寄り、関節推定に使う切り出し領域がフレーム外にはみ出しているためです。
画面上部に「手がカメラの端に近いです」と出ているときがこの状態です。端に近いほど自動で
安定化を強めますが、それでも揺れるなら `active_margin_bottom` を大きくする（0.40 など）と、
手がもっと上にあるうちに画面の一番下へ届くようになります。`edge_stabilizer_boost` を 2.5 に
上げるのも有効です。
カメラを少し下向きにする、椅子を下げて手の位置を映像の中央寄りにするのも効果的です。
`cursor_landmark` が `index_tip` の場合は `palm` に戻すのが最も効果的です。

**クリックが勝手に発動する**
左クリックは「親指を一度離してから近づけ、2フレーム連続で閉じた」ときだけ成立します。
それでも多いなら `pinch_on` を 0.35 に下げるか、`pinch_confirm_frames` を 3 にしてください。
逆にクリックが反応しにくいときは、親指をいったんしっかり離してから（黄色いリングが出てから）閉じてください。

**クリックが狙った位置からずれる**
黄色いリング（カーソル固定）が出てから指を閉じてください。`cursor_landmark` を
`index_tip` にしている場合はピンチ動作で基準点が動くので、`palm` か `index_mcp` に戻してください。
**動かしている途中でカーソルが止まる（黄色いリングが出る）**
固定は「親指が人差し指へ近づいてきた」ときだけ発火し、手が30px以上動くか1秒経つと自動で解除されます。
それでも頻発するなら `pinch_arm` を 0.55 程度に下げるか、0 にして固定機能を切ってください
（基準点が `palm` ならピンチしてもカーソルは動かないので、固定なしでも実用になります）。

**右クリックしたいのに左クリックになる**
薬指ピンチ時に人差し指をしっかり伸ばして、親指から離してください。

## 制限事項

- レイテンシは概ね50〜100msです。精密なドラッグ作業よりも、プレゼン操作や
  大きなボタンの操作に向いています。
- 腕を上げ続けるため長時間の連続使用は疲れます（いわゆるゴリラアーム）。
- カーソル移動・オーバーレイ表示はプライマリモニタの範囲が対象です。
- 画面スケーリング環境でもずれないようDPIアウェアで動作します。

## ファイル構成

```
scripts/
  hand_mouse.py          メインアプリ（カメラ→判定→マウス操作のループ）
  download_model.py      検出モデルのダウンロード
  hand_mouse_config.json 設定（初回起動時に自動生成）
  hm_core/
    camera.py            カメラ取得（別スレッドで最新フレームを保持）
    config.py            設定の読み書き
    filters.py           One Euro Filter（手ブレ抑制）
    gestures.py          ランドマーク→ジェスチャー判定
    hotkeys.py           グローバルホットキー（安全装置）
    mouse.py             Windows API経由のマウス／キーボード操作
    overlay_window.py    デスクトップ透過オーバーレイ（手の骨格表示）
    overlay.py           カメラプレビューのHUD描画（日本語対応）
models/
  hand_landmarker.task   MediaPipeの検出モデル
```
